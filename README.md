# Групповой проект №5

## Бизнес-заказчик

В качестве бизнес заказчика проекта выбран Рослесхоз или аналогичная организация, занимающаяся мониторингом, профилактикой и реагированием на лесные пожары.

В рамках проекта рассматривается прототип цифровой платформы мониторинга лесных пожаров. Такая платформа может использовать погодные, экологические и спутниковые данные для раннего выявления зон риска и оперативного обнаружения признаков пожара.

Основная цель платформы  помочь службам мониторинга быстрее определять опасные территории, приоритизировать проверку участков и эффективнее распределять ресурсы для предотвращения и тушения лесных пожаров.

## Бизнес задачи

Лесные пожары наносят значительный экологический и экономический ущерб. Для организаций, занимающихся мониторингом лесов, важна не только реакция на уже возникший пожар, но и раннее предупреждение.

Предлагаемое решение может использоваться так:

Сначала платформа собирает погодные, экологические и региональные данные. Эти данные передаются в табличную модель, которая оценивает риск возникновения пожара. После этого система выделяет зоны с высоким риском и направляет их на дополнительную проверку по спутниковым изображениям. Модель компьютерного зрения анализирует изображения и определяет, есть ли на них признаки пожара. На основе результатов двух моделей система формирует приоритеты для мониторинга и реагирования.

Наше решение:

- помогает заранее находить зоны повышенного риска

- ускоряет обнаружение пожаров

- снижает объём ручной проверки спутниковых снимков

- помогает приоритизировать выездные проверки

- повышает эффективность распределения ресурсов

- может снизить ущерб от позднего обнаружения пожара

!Важно, что модель не заменяет специалистов и службы реагирования. Она используется как инструмент поддержки принятия решений.

Поэтому для обоих частей проекта формулируем следующие задачи:

№1: прогноз риска возникновения лесного пожара по табличным данным.

Организации, отвечающей за мониторинг лесов, важно заранее понимать, в каких районах риск возникновения пожара выше. Это позволяет усилить наблюдение, заранее направить патрули, подготовить технику и быстрее реагировать на потенциально опасные ситуации.

Для решения этой задачи используется датасет Global Wildfire Dataset:

https://www.kaggle.com/datasets/vijayaragulvr/wildfire-prediction

На основе экологических, погодных и других признаков модель должна предсказывать вероятность возникновения пожара или класс риска пожара.

№2: обнаружение признаков пожара по спутниковым изображениям.

Даже если территория имеет высокий риск пожара, службам мониторинга нужна визуальная проверка. Спутниковые изображения позволяют автоматически определить, есть ли на участке признаки пожара.

Для решения этой задачи используется датасет Wildfire Prediction Dataset:

https://www.kaggle.com/datasets/abdelghaniaaba/wildfire-prediction-dataset

Модель должна классифицировать спутниковое изображение как Wildfire или No Wildfire.

Первая модель заранее определяет зоны повышенного риска, а вторая модель помогает подтвердить наличие пожара по спутниковым изображениям - таким образом получаем связанные задачи

## Формулировка задач в терминах глубинного обучения

Наши задачи будут решаться с помощью технологий глубинного обучения, поэтому опишим задачи так:

Задача 1: 
Для табличной части используется полносвязная нейронная сеть, потому что по требованиям проекта первая задача должна решаться на табличных данных с помощью fully connected neural network.

Планируется сравнить минимум три конфигурации MLP.

Первая модель: простая MLP baseline.

Архитектура:

Эта модель нужна как базовый вариант. Она показывает, может ли простая полносвязная сеть находить закономерности в табличных признаках.

Вторая модель: более глубокая MLP.

Архитектура:

Эта модель нужна, чтобы проверить, улучшает ли увеличение глубины сети качество прогноза. Более глубокая сеть может лучше улавливать сложные нелинейные связи между погодными и экологическими признаками.

Третья модель: MLP с регуляризацией.

Архитектура:

В этой модели используются Dropout, Batch Normalization и Weight Decay. Она нужна для снижения переобучения и проверки того, улучшает ли регуляризация качество на validation и test.

Задача 1: прогноз риска пожара по табличным данным.

С точки зрения deep learning это задача supervised learning на табличных данных.

Вход модели: вектор признаков, описывающих погодные, экологические и региональные условия.

Выход модели: вероятность возникновения пожара или класс риска.

Тип задачи: классификация (бинарная или нет, надо обсудить будет. Если в датасете будет несколько уровней риска, задача может быть сформулирована как многоклассовая классификация.
)

Основная модель: полносвязная нейронная сеть, то есть MLP.

Основные метрики:

- Accuracy
- F1 score
- Recall
- ROC-AUC

Особенно важен Recall, потому что для задачи мониторинга пожаров опаснее пропустить реальный пожар или высокий риск, чем ошибочно отметить территорию как опасную.

Задача 2: обнаружение пожара по спутниковым изображениям.

С точки зрения глубинного обучения это задача supervised image classification.


Для задачи классификации спутниковых изображений используются сверточные нейронные сети и модели transfer learning. Это подходит для работы с изображениями, потому что CNN-архитектуры умеют выделять визуальные признаки: формы, текстуры, границы, участки дыма, огня или выгоревшей территории.

Планируется сравнить минимум три архитектуры.

Первая модель: простая CNN baseline.

Архитектура:

Эта модель нужна как базовый вариант для image-задачи. Она обучается с нуля и показывает, какого качества можно достичь без использования предобученных моделей.

Вторая модель: ResNet.

ResNet выбрана как более сильная сверточная архитектура. Её преимущество — residual connections, которые помогают обучать более глубокие сети и уменьшают проблему затухающих градиентов.

В проекте можно использовать предобученную ResNet и заменить последний классификационный слой под два класса: Wildfire и No Wildfire.

Третья модель: EfficientNet или MobileNet.

EfficientNet или MobileNet выбраны как более эффективные архитектуры для классификации изображений. Они позволяют сравнить не только качество, но и вычислительную эффективность модели.

Это важно с бизнес-точки зрения, потому что реальная система мониторинга должна обрабатывать большое количество спутниковых изображений достаточно быстро.


Вход модели: спутниковое изображение.

Выход модели: класс изображения.

Классы:

- Wildfire — на изображении есть признаки пожара

- No Wildfire — на изображении нет признаков пожара

Основные метрики:

- Accuracy
- Precision
- Recall
- F1 score
- Confusion Matrix

особенно важен Recall по классу Wildfire, потому что системе важно минимизировать количество пропущенных пожаров
